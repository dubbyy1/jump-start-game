# Twelve Seasons
A simple 2D platformer with 12 levels

## Controls
- Movement: ←  →  or A D
- Jump: Space or W or ↑
- Camera: ↓or S to look down
- Other: Esc to exit

## Features
- Springs: fly into the sky!
- Spikes: maybe don't touch those
- Sun (deadly laser): sun deals damage, so stay in the shade!

Textures from [Kenney](https://kenney.nl/assets/pixel-platformer)

> Note: Game currently only has 7 levels
